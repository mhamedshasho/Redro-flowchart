# Redro Flowchart

An offline-first flowchart editor for learning and simulating algorithms.

## Editions
- `desktop.html` — desktop editor
- `mobile.html` — touch-oriented mobile editor
- `index.html` — automatic device selector

The app is designed as a standalone HTML application. Open `index.html` through GitHub Pages to select the best edition for the current screen.

## GitHub Pages
In repository Settings → Pages, select **Deploy from a branch**, choose `main` and `/ (root)`.
