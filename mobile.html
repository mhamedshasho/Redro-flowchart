كيف تستخدم Redro Flowchart؟

1
أضف الأشكال
اضغط على Start ثم أضف Read أو Process أو If أو غيرها من الشريط السفلي/الجانبي.
2
اكتب التعليمة
حدد الشكل، ثم عدّل النص من لوحة الخصائص. مثال: داخل Process اكتب A = 5.
3
اربط الأسهم
اضغط «ربط سهم»، ثم اضغط شكل البداية وبعده شكل النهاية. اختر السهم لتعديل نوع مساره وتسميته.
4
شغّل الخوارزمية
اضغط تشغيل أو خطوة واحدة. عند Read سيطلب البرنامج قيمة، وعند Write ستظهر النتيجة في سجل المخرجات.
5
احفظ عملك
زر حفظ ينزّل ملف مشروع JSON، ويمكن فتحه لاحقاً من زر فتح. PNG للصورة وPDF للطباعة.
تذكير من المنهاج

Start وEnd للنهايات الطرفية، Read وWrite للإدخال والإخراج، Process للمعالجة الحسابية، If للشرط والقرار، Loop للتكرار، Connector لربط أجزاء المخطط، والأسهم لتحديد اتجاه سير التنفيذ.
